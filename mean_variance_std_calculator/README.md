# Mean-Variance-Standard Deviation Calculator

Project latihan freeCodeCamp, Python + NumPy.

## File
- `mean_var_std.py` — fungsi `calculate(numbers)` yang diperlukan freeCodeCamp.
- `main.py` — menjalankan contoh input dan pengujian.
- `test_module.py` — tes lokal buatan, **bukan** test resmi freeCodeCamp.
- `requirements.txt` — dependensi NumPy.

## Cara menjalankan

Buka terminal dalam folder project, lalu jalankan:

```bash
python -m pip install -r requirements.txt
python main.py
```

Untuk hanya menjalankan tes lokal:

```bash
python -m unittest test_module.py
```

Di sebagian sistem Linux/macOS gunakan `python3` sebagai pengganti `python`.

Untuk mengerjakan starter project freeCodeCamp asli, salin isi `mean_var_std.py` ke file dengan nama sama di proyek starter, lalu jalankan tes resmi yang disediakan.
